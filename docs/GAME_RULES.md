# ゲームルール v0.1

本書をゲームルールの唯一の基準とする。「確定」は依頼仕様、「補足」はその実装上の解釈、「未確定」は実装前に決定が必要な事項を表す。未確定項目について暗黙の既定値を設けない。技術方式は[ARCHITECTURE.md](ARCHITECTURE.md)、情報保護は[SECURITY.md](SECURITY.md)を参照する。

## 1. 基本・用語（確定）

- プレイヤー2人の完全非同期ターン制。同時接続は不要。
- 盤面は6列×8段、突破口2か所、浮島なし。各プレイヤー23枚。
- 双方が秘密配置を完了した後、サーバーが先手をランダム決定する。
- 自分の手番に自軍の1駒だけを動かす。1手終了ごとに状態と全着手履歴を永続保存する。
- 現実時間による手番期限はなく、経過時間だけで敗北・引き分けにしない。
- 自分の端末でブラウザを閉じても、数日・数週間・数か月後の再ログインで再開できる。

「前方」は所有者の自陣から敵陣へ向かう方向、「後方」はその逆。「直後」は所有者から見た後方の隣接1マス。「将官」は大将・中将・少将。「占領可能駒」は大将・中将・少将・大佐・中佐・少佐を指す。表示の上下反転によって意味は変わらない。

## 2. 駒の構成（確定）

| 駒 | 1人当たり枚数 | 司令部占領 |
| --- | ---: | --- |
| 大将 | 1 | 可 |
| 中将 | 1 | 可 |
| 少将 | 1 | 可 |
| 大佐 | 1 | 可 |
| 中佐 | 1 | 可 |
| 少佐 | 1 | 可 |
| 大尉 | 2 | 不可 |
| 中尉 | 2 | 不可 |
| 少尉 | 2 | 不可 |
| 飛行機 | 2 | 不可 |
| タンク | 2 | 不可 |
| 工兵 | 2 | 不可 |
| 地雷 | 2 | 不可 |
| 騎兵 | 1 | 不可 |
| スパイ | 1 | 不可 |
| 軍旗 | 1 | 不可 |

検算：1枚の種類が9種類、2枚の種類が7種類。9 + 7 × 2 = **23枚／人、46枚／対局**。占領可能駒は6枚／人。

## 3. 初期配置（確定）

自陣内で自由に秘密配置する。地雷・軍旗を突破口入口に置いてはならず、軍旗を自陣最後列に置いてはならない。司令部への地雷配置は許可する。

配置完了時は全23枚が指定構成どおりに存在し、1マスに複数駒を置かず、禁止位置・自陣外への配置がないことをサーバーで検証する（補足）。双方の完了までは通常の着手を受理しない。自陣・入口・司令部の正確な座標と配置確定後の変更可否は未確定（U1、U5）。

## 4. 移動

| 駒 | 移動（確定） |
| --- | --- |
| 大将・中将・少将・大佐・中佐・少佐・大尉・中尉・少尉・スパイ | 前後左右1マス |
| タンク・騎兵 | 前後左右1マス、または前方2マス。2マス移動の中間に駒があれば不可 |
| 工兵 | 前後左右に任意の距離。駒を飛び越えられない |
| 飛行機 | 前後に任意の距離、左右1マス。味方駒は飛び越えられるが敵駒は飛び越えられない。突破口を使わず敵陣へ進入できる |
| 軍旗・地雷 | 移動不可 |

飛行機以外が自陣・敵陣の境界を越える場合、2つの突破口だけを利用可能。

補足：移動距離は1以上で、斜め移動・途中の方向転換・盤外移動・同位置への着手は不可。味方のいるマスには停止できない。空きマスへの停止は移動、敵のいるマスへの停止は戦闘となる。工兵・飛行機は通過経路と停止位置を別々に検証する。突破口の制限は長距離移動で境界をまたぐ場合にも適用する。

## 5. 戦闘

### 確定する個別ルール

通常階級は **大将 > 中将 > 少将 > 大佐 > 中佐 > 少佐 > 大尉 > 中尉 > 少尉**。同種同士は相打ちで双方除去。

| 特殊駒 | 戦闘性能 |
| --- | --- |
| 飛行機 | 大将・中将・少将に負け、それ以外には勝つ |
| タンク | 将官・飛行機・工兵・地雷に負け、それ以外には勝つ |
| 地雷 | 飛行機・工兵には負けて地雷のみ除去。その他の駒が攻撃した場合は双方除去 |
| 工兵 | 地雷・スパイ・タンクに勝ち、その他には負ける |
| 騎兵 | スパイ・工兵に勝ち、その他には負ける |
| スパイ | 大将にだけ勝ち、その他には負ける |

軍旗は移動不能。所有者から見た直後の味方駒と同じ戦闘性能を持ち、特殊駒の性能も継承する。直後に味方駒がいない場合は戦闘で必ず敗北する。移動能力は継承しない。

### 判定順序・結果の補足

個別の「その他」よりも明示された例外を優先し、次の順で判定する。これにより、例えばタンク対地雷はタンクのみの敗北ではなく双方除去となる。

1. 戦闘直前の盤面で軍旗の直後を調べる。味方駒がなければ軍旗の敗北。存在すれば、軍旗の戦闘上の種類をその味方駒の種類として以下を適用する。
2. 戦闘上の種類が同じなら双方除去。「その他に勝つ／負ける」より同種相打ちを優先する。
3. 地雷に対しては飛行機・工兵だけが生存し、それ以外は双方除去。軍旗が地雷の性能を継承している場合も同じ。
4. スパイ対大将はスパイの勝利。
5. 残る組み合わせは通常階級と特殊駒の表で判定する。地雷以外は攻撃側・防御側によらず同じ強弱を用いる。

攻撃側だけが生存した場合は移動先へ進み、防御側だけが生存した場合はその場に残る。相打ちなら両駒を除去して移動先を空ける。軍旗が戦闘しても直後の味方駒自体は除去しない。軍旗の性能は配置時に固定せず戦闘ごとに評価する。軍旗の除去自体は勝利条件ではない。

この補足は軍旗の「同じ戦闘性能」や例外の優先順位を具体化したものであり、新しい駒能力を追加しない。

## 6. 情報秘匿（確定）

- 自軍の種類は表示する。敵軍の生存駒はすべて不明駒として表示する。
- 戦闘後も敵駒の種類を直接公開しない。合法的に知り得る戦闘結果のみ表示する。
- 自分の除去された駒の種類は確認可能。敵の除去された駒の種類は確認不可。
- 特殊な移動や戦闘結果から種類を推測できることは許容する。
- 敵駒の本当の種類は相手クライアントへ送信しない。履歴・再接続でも同じ制限を適用する。

補足：表示可能な戦闘結果は、着手元・着手先・どちらが除去されたか・戦闘後の占有状態・確定した対局結果。軍旗の継承元や戦闘上の種類を公開しない。対局終了を理由とする敵種類の公開例外も設けない。

## 7. 勝利と引き分け

以下のいずれかで勝利する（確定）。

1. 占領可能な自軍駒で敵司令部を占領する。
2. 敵の占領可能駒をすべて除去する。

戦闘が50手連続で発生しなかった場合は自動引き分け。現実時間の経過だけでは引き分けにならない（確定）。

補足：「1手」は片方のプレイヤーの受理された1着手であり、両者の1往復ではない。連続非戦闘手数は対局開始時0、戦闘なしの着手で1加算、戦闘ありの着手で0に戻す。無効な要求・再送・配置操作は数えない。司令部占領は、戦闘を解決した後に占領可能駒が生存して敵司令部に停止することを意味する。

同時成立・合法手なしの扱い等は次節の決定が必要。対局終了後は着手を受理しない。

## 8. 実装前の未確定事項

| ID | 決定が必要な内容 | 未決定の影響 |
| --- | --- | --- |
| U1 | 共通盤面座標、各自陣の範囲、境界、2つの突破口と両側入口、各司令部のマス数・座標 | 配置・移動・占領判定を確定できない。6×8から座標を推定して固定しない |
| U2 | 占領不可の駒が敵司令部に進入・停止・通過できるか | 「占領できない」が進入禁止かどうかは元仕様にない |
| U3 | 相打ちで双方の最後の占領可能駒が同時除去された場合の結果、および勝利と50手引き分けが同時成立した場合の優先順位 | 終局処理を一意に決められない |
| U4 | 手番側に合法手が一つもない場合の扱い | パス・敗北・引き分けのいずれも元仕様にない。放置時間による解決は禁止 |
| U5 | 配置完了後の再編集・確定解除の可否と、その締切となる状態 | 非同期の配置確定処理に影響 |

これらが決まるまでは本書は初期仕様であり、全ゲーム処理の実装開始条件を満たさない。決定時は本書を更新し、他文書との整合性を確認する。

# ゲームルール v0.1

本書をゲームルールの唯一の基準とする。承認済み仕様を正式仕様として記載し、説明上の補足と未解決事項を区別する。技術構成は[ARCHITECTURE.md](ARCHITECTURE.md)、情報保護は[SECURITY.md](SECURITY.md)を参照する。

## 1. 基本・正規盤面座標

- プレイヤー2人の完全非同期ターン制。同時接続は不要。
- 物理盤面は6列×8段、列A〜F、行1〜8。突破口2か所、浮島なし。
- サーバー内部の正規座標はPlayer 1視点で固定する。
- 各プレイヤー23枚。双方の配置をLOCKしてサーバーが先手をランダム決定する。
- 自分の手番に自軍1駒だけを動かす。受理した着手ごとに状態と棋譜を永続保存する。
- 現実時間による手番期限・配置期限はない。ブラウザを閉じても数日・数週間・数か月後の再ログインで再開できる。

| 所有者 | 自陣 | 最後列 | 前方 | 後方 | 自軍突破口入口 |
| --- | --- | --- | --- | --- | --- |
| Player 1 | rows 1〜4 | row 1 | row+1 | row-1 | B4、E4 |
| Player 2 | rows 5〜8 | row 8 | row-1 | row+1 | B5、E5 |

境界はrow 4とrow 5の間。突破口は **B4 <-> B5、E4 <-> E5** の2本のみ。飛行機以外が境界を越える場合、この接続のみ利用できる。長距離移動にも適用する。

表示は各自陣が常に画面下になるよう必要に応じて180度回転する。サーバーの座標・方向は回転しない。タンク・騎兵・軍旗等の方向依存判定は必ず所有者に対応する上表を使用する。「直後」は後方の隣接地点、「将官」は大将・中将・少将、「占領可能駒」は大将・中将・少将・大佐・中佐・少佐を指す。

## 4. 初期配置・READY・LOCK

各自の23枚すべてを使い、自陣23地点をすべて埋める秘密配置とする。1地点に1駒のみ。

- 地雷・軍旗は自軍突破口入口（Player 1：B4、E4／Player 2：B5、E5）へ配置不可。
- 軍旗は自軍最後列へ配置不可。HQも最後列なので軍旗配置不可。
- 地雷はHQへ配置可能。
- 配置確定時、全23枚の構成・自陣内・全地点占有・禁止位置をサーバーで検証する。

対局開始前は配置を編集可能。「配置確定」でREADYとなる。READY後も未開始ならREADY解除後に再編集できる。双方が同時にREADY状態であることをサーバーが確認した時点で、次を原子的に実行する。

1. 両配置をLOCKする。
2. 以後の編集・READY解除を禁止する。
3. 先手をランダム決定する。
4. 対局状態をPLAYINGへ変更する。

READY解除と開始が競合した場合はサーバーが直列化し、LOCKが先に成立したら解除を拒否する。READY解除が先なら片側が未READYなので開始しない（補足）。配置編集・READY・READY解除に現実時間の期限は設けない。

## 6. 軍旗と戦闘の正本

### 軍旗の有効駒種

軍旗は移動不能。戦闘直前の盤面で、所有者から見て直後に存在する味方駒の戦闘性能を継承する。後方駒の移動・除去に応じて即座に変化し、配置時の値を固定しない。特殊駒の特殊戦闘性能も継承する。移動能力は継承しない。

軍旗の有効駒種を戦闘前に後方駒の種類へ置き換えてから下表を参照する。後方に味方駒がなければ軍旗は敗北する。有効駒種が同じ場合も相打ち。除去対象は軍旗自身であり、性能を与えた後方駒は除去しない。軍旗の除去自体は勝利条件ではない。

### 戦闘後の盤面

- 攻撃側勝利：攻撃側が目的地点へ移動し、防御側を除去する。
- 防御側勝利：攻撃側を除去し、防御側は元位置に残る。
- 相打ち：双方を除去し、目的地点は空になる。

## 7. 終局判定・自動PASS・50手

合法着手を受理した後、以下の順で処理する。先に終局が成立したらそこで結果を確定し、以降の判定・手番遷移を行わない。以下の盤面確定はトランザクション内の確定を意味し、途中状態を外部公開しない。

1. 移動と戦闘を完全に解決する。非戦闘カウンターも今回の着手に従って更新する。
2. 盤面状態を確定する。
3. 敵HQ占領を判定する。今回の着手で占領可能駒が敵HQへ生存して停止したら着手側の勝利。
4. 双方の占領可能駒の残存数を判定する。双方0枚なら引き分け、片側だけ0枚なら反対側の勝利。
5. 合法手の有無を判定する。双方に合法手がなければ即時引き分け。次に手番となる側だけに合法手がなければ、自動PASSを必要とする状態として扱う。
6. 非戦闘カウンターが50に達したら引き分け。
7. 未終局なら次手番へ遷移する。次手番側に合法手がなければ自動PASSを記録して相手へ手番を移す。

補足：5で次手番候補を検査し、7で遷移する。6で終局したら不要なPASSや次手番を作らない。双方の最後の占領可能駒が同一戦闘で相打ちとなり双方0枚の場合は4で引き分け。占領等の勝利条件は50手引き分けより優先する。

手番側に合法手がなくても敗北にはしない。サーバーが自動PASSとして相手へ手番を移し、棋譜にシステムイベントとして記録する。プレイヤーによる任意のPASSは認めない（補足：自動PASSだけを定義する）。対局開始時の先手についても合法手を検査し、同じ自動PASS・双方合法手なしの規則を適用する。

非戦闘カウンターは開始時0。プレイヤーの受理された合法着手1回を1手とし、戦闘なしなら+1、戦闘ありなら0へ戻す。自動PASS・無効要求・再送・配置操作は加算しない。自動PASSではリセットもしない。現実時間はこの判定に一切使用しない。終局後の着手は受理しない。

## 8. 対局中の秘匿と終局後公開

対局開始前・PLAYING中は、敵の真の種類を相手クライアントへ送らない。自軍の種類と自分の除去駒の種類は表示可能。敵生存駒は不明駒とし、敵除去駒の種類も表示しない。

戦闘後も対局が継続する場合は敵種類を直接公開せず、着手元・着手先・除去された側・戦闘後の占有状態など合法的な結果だけを表示する。軍旗の継承元・有効駒種も秘匿する。特殊移動や結果から種類を推測できることは許容する。

**終局後は、サーバーが終局状態と認証済み参加者であることを確認した場合に限り、双方に以下を閲覧可能にする。**

- 当該対局の全駒種類（除去駒を含む）。
- 対局開始時にLOCKした双方の初期配置。
- 完全棋譜と各戦闘の双方の駒種類。

補足：初期配置は編集中の履歴ではなくLOCK時の配置。非参加者・未認証者への公開は許可しない。終局をクライアントの申告から判断しない。終局前の棋譜・API・DB・再接続・通知にも秘匿を適用する。

## 9. 通信・ルール版の正式方針

- 各着手に一意な `client_move_id` を付け、再送を冪等化する。
- ゲーム状態は単調増加する `state_version` を持ち、古い版に基づく新規着手を拒否する。
- API応答は認証済み閲覧者ごとに生成し、終局前は相手秘密情報を含めない。終局後は8節の認可に従う。
- 作成時に `ruleset_version` を固定保存する。進行中に変更せず、ルール改訂後も既存対局は作成時の版で解釈する。

### R1：HQの仮想アンカーと移動幾何（正式仕様）

#### 論理地点と仮想アンカー

| HQ | 物理領域 | 移動幾何専用の仮想アンカー | 双方向の1マス隣接地点 |
| --- | --- | --- | --- |
| HQ-P1 | C1+D1 | C1-anchor、D1-anchor | B1、C2、D2、E1 |
| HQ-P2 | C8+D8 | C8-anchor、D8-anchor | B8、C7、D7、E8 |

仮想アンカーは独立した盤面地点ではなく、個別の配置・占有はできない。HQ全体で1論理地点・最大1駒、各陣営23配置地点を維持する。アンカー同士の内部移動を盤面上の1マス移動として数えない。

HQを始点または終点とする1回の移動では、経路に対応するアンカーをちょうど1つ使用する。縦方向のC列はC-anchor、D列はD-anchorを使う。横方向は正規座標でHQより左のA/B側にC-anchor、右のE/F側にD-anchorを使う。選択したアンカー座標と通常地点の座標で、同一直線上の距離・中間地点を計算する。

HQは始点または終点にだけ使用でき、中間地点にはできない。C側から入ってD側へ出る逆側退出、同一手中の列変更・縦横の方向転換、HQを通過して反対側へ進むことは禁止する。長距離移動もHQへ到達した時点で終了する。この制約はHQが空でも、味方駒を飛び越せる飛行機でも適用する。

#### 通常1マスと前方2マス

通常の前後左右1マス移動能力を持つ駒は、上表のHQと各隣接地点との間を双方向に1マスとして移動できる。例えばC2、D2、B1、E1のいずれからもHQ-P1へ進入でき、HQ-P1からもそれぞれへ退出できる。Player 2側も対称。味方のいる目的地点へは停止できず、敵がいれば既存の戦闘・占領判定を適用する。軍旗・地雷に移動能力を追加しない。

タンク・騎兵の前方2マスは所有者の前方定義を使用し、1回の移動でC/Dレーンを変更しない。

| 所有者・始点 | 目的地点 | 幾何経路 | 駒があれば禁止となる中間地点 |
| --- | --- | --- | --- |
| Player 1・HQ-P1 | C3 | C1-anchor -> C2 -> C3 | C2 |
| Player 1・HQ-P1 | D3 | D1-anchor -> D2 -> D3 | D2 |
| Player 2・C3 | HQ-P1 | C3 -> C2 -> C1-anchor | C2 |
| Player 2・D3 | HQ-P1 | D3 -> D2 -> D1-anchor | D2 |
| Player 2・HQ-P2 | C6 | C8-anchor -> C7 -> C6 | C7 |
| Player 2・HQ-P2 | D6 | D8-anchor -> D7 -> D6 | D7 |
| Player 1・C6 | HQ-P2 | C6 -> C7 -> C8-anchor | C7 |
| Player 1・D6 | HQ-P2 | D6 -> D7 -> D8-anchor | D7 |

中間地点は味方・敵のどちらがいても通れない。C2経由でD3へ進む等の列変更は禁止。HQの所有者ではなく移動する駒の所有者が前方を決めるため、表の2マス経路を逆向きに使えるかはその駒の所有者で判定する。

#### 工兵の長距離移動

1回の移動は次の直線ray（直線経路）のうち1本だけを使う。HQへ向かう移動は同じrayを逆方向に使う。

| HQ | Cレーン | Dレーン | 正規座標の左 | 正規座標の右 |
| --- | --- | --- | --- | --- |
| HQ-P1 | C1-anchor -> C2 -> C3 -> C4 | D1-anchor -> D2 -> D3 -> D4 | C1-anchor -> B1 -> A1 | D1-anchor -> E1 -> F1 |
| HQ-P2 | C8-anchor -> C7 -> C6 -> C5 | D8-anchor -> D7 -> D6 -> D5 | C8-anchor -> B8 -> A8 | D8-anchor -> E8 -> F8 |

通常どおり中間地点に駒があればそれより先へ進めない。敵がいる地点で停止して戦闘することは可能で、味方がいる地点には停止できない。例えばC4 -> C3 -> C2 -> HQ-P1は中間が空なら移動可能だが、C4 -> HQ-P1 -> E1は中継・方向転換のため禁止。

補足：上表のC/Dレーンは工兵の場合、突破口のない境界（C4/C5、D4/D5）までで止まる。HQのアンカーを使っても突破口制限は変わらず、C/Dレーンで境界を越えることはできない。左右のrayは盤端A/Fで終わる。

#### 飛行機

飛行機もC/Dレーンを1本だけ選び、HQを中間地点にしない。前後は任意距離、左右は1マス、味方駒を飛び越せるが敵駒は飛び越せないという既存能力を維持する。敵のいる目的地点での戦闘、味方のいる地点への停止禁止も同じ。

縦のrayは工兵と同じアンカーから延ばすが、飛行機は突破口なしで境界を越えられる。例えばHQ-P1からC7への経路はC1-anchor -> C2 -> … -> C7となる（敵の中間駒がいないこと等が条件）。Dレーンも対称。HQへの進入では到着したHQで必ず停止し、そこから別rayへ続けない。

横方向はHQ-P1とB1/E1、HQ-P2とB8/E8の間の1マスだけ。HQからA/Fまでの横長距離移動を許可しない。味方駒のいるHQを飛び越えて反対側へ行くことも禁止する。

#### 別の手での別ポート退出

ある手でHQへ進入して移動を終了したら、進入アンカー（ポート）を次の手の制約として保持しない。次にその駒を動かす手ではHQを新しい始点とし、移動能力に従い任意の合法な接続先・rayを選べる。進入ポートを駒の永続状態に保存しない。

例えばC2 -> HQ-P1で手を終了し、後の同じプレイヤーの手でHQ-P1 -> D2へ動くことは合法になり得る。一方、同一手のC2 -> HQ-P1 -> D2は禁止。補足：進入時に終局した場合には次の着手はなく、退出は対局が継続している場合に限る。

#### 軍旗の直後と対称性

軍旗所有者の後方を物理座標で1マス求め、該当座標がHQ領域なら同じ論理HQへ対応させる。

| 軍旗所有者 | 軍旗位置 | 後方の物理座標 | 参照する論理地点 |
| --- | --- | --- | --- |
| Player 1 | C2 | C1 | HQ-P1 |
| Player 1 | D2 | D1 | HQ-P1 |
| Player 2 | C7 | C8 | HQ-P2 |
| Player 2 | D7 | D8 | HQ-P2 |

HQに軍旗所有者と同じ側の駒がいれば、その駒を直後の味方駒として扱い、戦闘直前の性能を参照する。HQが空または敵駒で占有されていれば、直後の味方駒は存在しない。軍旗は移動能力・司令部占領資格を継承しない。

補足：C2とD2の両方（Player 2ではC7とD7）が同じHQ駒を参照できるのは、位置対応の説明である。承認文の「両方に同一所有者の軍旗が存在する場合」は幾何上の仮定であり、正式な駒構成は軍旗1枚／人のままなので実対局では同時に発生しない。軍旗枚数や配置制約を変更しない。

全規則はPlayer 1とPlayer 2で180度回転対称に適用する。補足：正規座標の回転対応はA↔F、B↔E、C↔D、row r↔9-rで、C1-anchor↔D8-anchor、D1-anchor↔C8-anchorとなる。正規座標そのものはPlayer 1視点で固定し、クライアント表示の向きは判定へ影響させない。

#### 未解決事項：両端がHQとなる飛行機の移動

飛行機の既存の前後長距離移動・突破口不要という能力では、HQ-P1とHQ-P2の間の直接移動が候補となる。しかしCレーンならC1-anchorとC8-anchor、DレーンならD1-anchorとD8-anchorが必要で、R1の「1回の移動でアンカーをちょうど1つ使用」と両立するかが未定義である。HQ通過・列変更は伴わないため、それらの禁止だけでは判定できない。

「各HQにつき1アンカー」と解釈して直接移動を許可するのか、別の扱いとするのかは承認が必要。許可する場合にはC/Dの2経路を区別して中間駒を検査する必要もある。本書では推測で許可・禁止を決めず、通常地点とHQの間の確定規則と分離する。既存の飛行機能力や占領資格を変更しない。

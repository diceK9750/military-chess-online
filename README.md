# military-chess-online
2-player asynchronous online strategy game inspired by military chess

日本の軍人将棋を基礎とする、2人用・スマートフォン優先の不完全情報型戦略ゲームです。各プレイヤーは別々の端末から自分の手番に操作し、同時接続なしで数日・数週間・数か月後にも対局を再開できます。現実時間による手番期限は設けません。

## 現状

初期仕様 v0.1 の文書化段階です。ゲーム、UI、バックエンドは未実装です。Supabaseプロジェクト作成、GitHub Pages設定、npm初期化、外部サービス登録・課金導入も行っていません。

## 仕様の基準

- [ゲームルール](docs/GAME_RULES.md)：駒、配置、移動、戦闘、勝敗、未確定事項。
- [初期アーキテクチャ案](docs/ARCHITECTURE.md)：永続化、認証、サーバー処理、再接続。
- [セキュリティ仕様](docs/SECURITY.md)：秘密情報、アクセス制御、不正操作への対策。

ルールの唯一の基準はGAME_RULES.md、必須の保護要件はSECURITY.mdです。ARCHITECTURE.mdの技術選択は初期案であり、確定ルールを変更しません。文書が矛盾した場合は実装で解釈せず文書を修正します。未確定事項は確定仕様と区別して記録しており、該当機能の実装前に決定が必要です。

公開先の第一候補はGitHub Pages、バックエンドの第一候補はSupabaseです。クライアントには敵駒の種類を渡さず、合法手・手番・戦闘はサーバーで検証・判定します。
